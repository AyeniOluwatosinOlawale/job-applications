Profiled CUDA kernel bottlenecks to deliver 3.8$\times$ throughput gains and 18$\times$ latency reduction. Comfortable with PyTorch, vLLM, SGLang, TensorRT-LLM — and with the infrastructure that keeps them running reliably under production load.
